# 🌾 Crop Recommendation System using Big Data

## 📌 Overview

This project is a Big Data–based Crop Recommendation System that predicts the most suitable crop based on soil nutrients and environmental conditions.

The system uses Hadoop for distributed storage, Hive for SQL-based querying, Apache Spark MLlib for machine learning, and Streamlit for an interactive web application.

---

## 🛠️ Technologies Used

- Docker
- Hadoop
- HDFS
- Apache Hive
- Apache Spark
- Spark MLlib
- Python
- Streamlit
- Git & GitHub

---

## 📊 Dataset

Crop Recommendation Dataset (Kaggle)

Features:
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH
- Rainfall

Target:
- Recommended Crop
